# 연혁 플로우 — 뷰어 (Timeline Flow Viewer)

플로우차트형 가로 타임라인으로 정리한 연혁 보드를 **읽기 전용으로 보여주는** 페이지입니다.
편집은 막혀 있고, 보는 사람은 둘러보고 상세 내용을 확인할 수 있습니다.

## 보는 사람이 할 수 있는 것

- 화면 끌어서 이동, Ctrl+휠 / 오른쪽 아래 버튼으로 확대·축소, `맞춤`으로 전체 보기
- 항목(노드) 클릭 → 상세 보기: 이미지, 내용, 참여자(나이·경과), 태그, 메모, 이전/다음 흐름
- 항목 이미지 클릭 → 크게 보기 (← → 키로 넘기기)
- 참여자 클릭 → 프로필, 관계, 관련 항목 / `흐름 보기`로 그 참여자의 흐름 강조
- 검색, 분류·태그·중요도 필터, 플로우 / 목록표 / 참여자 카드 보기 전환

## 보드 올리는 방법

1. 편집기에서 **저장 / 불러오기 → `board.json 받기`** 를 눌러 파일을 받습니다. (이미지 포함)
2. 이 저장소에 `board.json` 이름 그대로 올립니다. (`index.html`과 같은 위치)
3. GitHub Pages 주소를 열면 보드가 표시됩니다. 내용을 바꾸려면 `board.json`만 새로 올리면 됩니다.

`board.json`이 없으면 빈 화면에 안내가 나오며, 백업 JSON 파일을 화면에 끌어다 놓거나
상단 `JSON 열기`로 다른 보드를 미리 볼 수 있습니다. (끌어다 놓은 파일은 서버에 올라가지 않습니다)

## GitHub Pages 설정

**Settings → Pages → Build and deployment**
Source: `Deploy from a branch` · Branch: `main` / `/ (root)` → Save

1~3분 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.

## 기술 구성

- 순수 HTML / CSS / JavaScript 단일 파일 (외부 라이브러리 없음)
- 폰트: Google Fonts (Noto Sans KR, Noto Serif KR)
