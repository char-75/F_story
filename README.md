# 연혁 플로우 (Timeline Flow)

시간의 흐름을 **플로우차트 형태의 가로 타임라인**으로 정리하는 웹 도구입니다.
스토리보드·세계관 연혁, 프로젝트 마일스톤, 회사·조직 연혁, 역사 정리 등 어떤 연대기에도 쓸 수 있습니다.

설치나 빌드 없이 `index.html` 파일 하나로 동작합니다.

## 주요 기능

- **플로우 보드** — 항목(노드)을 자유롭게 배치하고, 관계선(화살표)으로 원인 → 결과를 연결
  - 디자인 툴처럼 자유 배치 + 정렬 가이드 (Alt: 가이드 끄기, Shift: 한 방향 이동)
  - `정리하기` — 현재 배치를 기준으로 정렬 강도(%)·간격(%)을 조절해 정돈
  - `연도순 자동` 배치 모드 지원
- **관계선**
  - 항목을 피해 지나가는 직각 경로 자동 계산, 선끼리 겹침 최소화
  - 선택 후 끝점 드래그로 출발/도착 항목 변경, 빈 곳에 놓으면 삭제
  - 가운데 손잡이로 경로 조정, 관계 이름 입력
- **구간 · 그룹 · 분류 · 태그** — 큰 시간 구분, 가로줄 묶음, 색상 분류, 키워드 필터
- **참여자** — 프로필(역할, 소속, 시작·종료 연도, 관계), 참여자별 흐름 강조와 경과/나이 표시
- **이미지** — 항목·참여자에 이미지 등록(끌어다 놓기·붙여넣기), 대표 이미지, 크게 보기
- **용어 설정** — 화면 용어를 용도에 맞게 변경 (스토리·세계관 / 프로젝트 / 회사 연혁 / 역사 정리 프리셋)
- **보기 전환** — 플로우 / 목록표 / 참여자 카드
- **저장 / 불러오기** — 백업 JSON(이미지 포함 선택), 연혁 텍스트(Markdown), CSV

## 사용 방법

1. `index.html`을 브라우저(Chrome, Edge, Safari, Firefox 최신 버전)로 엽니다.
2. 상단의 `＋ 구간`, `＋ 참여자`, `＋ 항목`으로 내용을 추가합니다.
3. 노드 오른쪽 ●를 클릭하면 다음 항목이 이어 붙고, 끌면 다른 항목과 연결됩니다.

### GitHub Pages로 바로 쓰기

저장소 **Settings → Pages → Branch: `main` / `/ (root)`** 로 설정하면
`https://<계정>.github.io/<저장소>/` 주소에서 바로 사용할 수 있습니다.

## 데이터 저장 안내

- 작업 내용은 **사용 중인 브라우저에만** 저장됩니다 (항목 데이터: localStorage, 이미지: IndexedDB).
- 다른 기기로 옮기거나 백업하려면 `저장 / 불러오기 → 백업 데이터(JSON)`를 복사해 보관하세요.
- 브라우저 데이터를 지우면 작업 내용도 함께 지워집니다.
